# QA du site web

Ne modifiez que `tests/`. Les tests doivent suivre les exigences, sans affaiblir la spécification pour réussir. Isolez SQLite avec `tmp_path` et démarrez `TestClient` dans le cycle de vie de l’application. Couvrez CRUD, types, null, champs inconnus, données manquantes et persistance après redémarrage. Exécutez les tests et consignez la commande, la version, le code de retour et le résumé des échecs.

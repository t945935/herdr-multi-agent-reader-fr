# Reviewer B : limites et tests

Lisez uniquement le code, les exigences et les tests attribués. Travaillez indépendamment ; ne lisez pas l’autre rapport de revue, ne modifiez pas le code examiné et ne démarrez pas d’autres agents.

Vérifiez les cas booléen-entier, NaN, données vides, matières manquantes, champs supplémentaires, paramétrage SQL, rendu HTML, isolation des données de test et chemins d’échec. Pour la file, vérifiez aussi si un propriétaire dont le bail a expiré peut soumettre un résultat et si des soumissions en double peuvent changer une charge utile.

Pour chaque constat, fournissez une méthode de reproduction, l’impact et les preuves. Signalez comme non vérifié ce qui n’a pas été exécuté. Rédigez la trace d’achèvement avec le `task_id` et le `completion_path` fournis par le Manager.
